Meu Contador API

Referência estática baseada no documento Swagger/OpenAPI do backend.

OpenAPI 3.1.0 Versão 1.0.0 Base local: http://127.0.0.1:8000

Endpoints

GET/health

Verifica se a API está disponível.

{
  "status": "ok"
}
GET/api/counter

Retorna o valor atual do contador e os limites configurados.

{
  "count": 0,
  "min": 0,
  "max": 10
}
POST/api/counter/increment

Incrementa o contador em um, sem ultrapassar o valor máximo. Retorna o estado atualizado.

{
  "count": 1,
  "min": 0,
  "max": 10
}
POST/api/counter/decrement

Decrementa o contador em um, sem ficar abaixo do valor mínimo. Retorna o estado atualizado.

{
  "count": 0,
  "min": 0,
  "max": 10
}
POST/api/counter/reset

Reseta o valor para zero, ajustando-o aos limites atuais quando zero estiver fora do intervalo.

{
  "count": 0,
  "min": 0,
  "max": 10
}
PUT/api/counter/limits

Atualiza os limites. O contador atual é ajustado para continuar dentro do novo intervalo.

Corpo JSON:

{
  "min": 0,
  "max": 10
}

Retorna o estado atualizado. Limites inválidos retornam HTTP 422.

Modelos
